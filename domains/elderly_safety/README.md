# Elderly Safety

Owner: Yuanbo Zhang. Requirements: AR-01 / UC-01; optional OR-04.

Store fall assessment, resident-response interpretation, caregiver contact policies and escalation logic here. Sprint 0 covers simulated fall input, initial assessment and recording. Sprint 1 adds confirmation, notification and optional multi-level escalation.

Reuse `models/`, `agents/`, `services/` and `tools/`; do not duplicate the shared agent framework. Tests belong in `tests/`, fixtures in `data/samples/`, and views in `ui/`.
